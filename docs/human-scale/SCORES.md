# Scores

Hand-given scores for bench builds, one row per build. Edit this file on
GitHub whenever there is time; `npm run bench:board` folds the rows into
[BENCH-BOARD.md](BENCH-BOARD.md) next to the screenshots. Scores are 1 to 5.
Leave a cell blank if you did not judge that axis. The run column is the
results folder name (the date prefix is enough: `2026-10-30T11-26`).

- **Design**: would a neighbor be glad to open this on their phone? Warm,
  legible, not generic.
- **RTP fit**: relational, seeded with real-feeling people and places,
  zero-setup, bounded jobs over chat boxes.
- **Completeness**: does it do what the prompt asked, end to end?
