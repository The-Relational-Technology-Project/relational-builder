# How is Relational Builder different from Claude or ChatGPT?

*For the specific job of building neighborhood tools.*

Claude and ChatGPT are excellent general-purpose assistants, and both can generate working code — Claude's Artifacts and ChatGPT's Canvas will happily build you a sign-up sheet or a little game. Relational Builder uses those same frontier models under the hood. The difference isn't the AI. It's everything wrapped around it: what the AI knows about community building, what happens after the code exists, and who can afford to use it.

A general chatbot ends where a neighborhood tool begins: with a real URL neighbors can open, real shared data, a way for neighbors to talk back, and a commons that gets richer with every build.

## The short version

**Claude and ChatGPT help you write code. Relational Builder helps you build a tool your neighbors actually use.**

Three things make the difference:

1. **The AI knows community building.** Every conversation carries the Relational Technology Project's principles and live retrieval from a commons of real tools, stories, and patterns from community builders. You're not starting from a blank page — you're building on what neighborhoods before yours have learned.

2. **The last mile is included.** A chatbot hands you code and wishes you luck with hosting, databases, and domains. Relational Builder takes the same build to a live URL with free hosting, a free shared data store with neighbor sign-in, feedback and health monitoring built in — the parts that usually stop a non-technical builder cold.

3. **Your build feeds the commons.** Finished tools, stories, and prompts can flow back to the community library (always consent-first, always credited), so the next builder in the next neighborhood starts further ahead. A chatbot conversation ends when you close the tab; a Relational Builder project makes the whole network smarter.

And in the spirit of the [90/10 principle](https://github.com/The-Relational-Technology-Project): the point of making the 10% (technology) this easy is to protect the 90% (presence and relationships). The faster the tool gets built, the sooner you're back on the block.
